A single warning label for a time machine, written in the deadpan voice of a genuine safety notice. It takes the hazard of an ancestor left behind in the past and turns it into a joke about the paperwork that follows: the stranded ancestor does not just vanish from history, they come back with claims. The surprise is saved for the very last words.

## Run

```sh
node main.ts
```

Writes the label to `/output/entry.txt` with no trailing newline.
